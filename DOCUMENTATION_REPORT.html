1. App Name and Introduction

App Name: VitalScale

Tagline: Smart Anthropometric & Health Companion for Adults

VitalScale is a modern, responsive, client-side Flutter Web application engineered specifically for the UI Design – Flutter Laboratory External Examination. It empowers users to monitor, evaluate, and track their physical health parameters through clinically validated anthropometric algorithms defined by the World Health Organization (WHO).

The application provides dual-unit body measurement inputs supporting both Metric (Centimeters, Kilograms) and Imperial (Feet & Inches, Pounds), instant Body Mass Index (BMI) computation rounded strictly to one decimal place, dynamic color-coded WHO category classifications, healthy weight range intervals, a custom animated segmented visual gauge, tailored dietary and lifestyle advice, and local history tracking with persistent browser storage.

VitalScale is developed in Dart using Flutter 3.x and is deployed as a live cloud web application through automated GitHub Actions workflows published to GitHub Pages.

2. Purpose and Objectives

2.1 Purpose

The purpose of VitalScale is to deliver a reliable, accessible, and user-friendly biometric screening dashboard that assists individuals in evaluating their body mass classification against clinical standards, while demonstrating professional proficiency in Flutter Web design, defensive input validation, asynchronous browser storage, and automated cloud CI/CD pipelines.

2.2 Objectives

  • To compute Body Mass Index accurately according to standard WHO formulas.
  • To enable seamless, live two-way switching between Metric (cm, kg) and Imperial (ft/in, lbs) units.
  • To handle defensive input validation preventing crashes from zero, negative, empty, or unrealistic values.
  • To calculate the estimated healthy weight range based on the user's height.
  • To provide a continuous visual gauge showing the user's BMI position via an animated indicator.
  • To persist calculation history locally using browser LocalStorage via SharedPreferences.
  • To offer one-tap viva examination test presets for immediate laboratory demonstration.
  • To provide Material 3 Dark and Light theme modes with responsive layout adaptability.
  • To deploy the application as a live web application on GitHub Pages.

4. Features and Functionality

4.1 Dual-Unit Body Parameter Inputs

VitalScale accommodates user preferences by supporting both Metric and Imperial units:

  • Height Selection: Centimeters (cm) mode with text field, slider (50–250 cm), and ±1 cm / ±5 cm buttons. Feet & Inches (ft & in) mode with dual fields and live conversions.
  • Weight Selection: Kilograms (kg) mode with text field, slider (10–200 kg), and ±1 kg / ±5 kg buttons. Pounds (lbs) mode with slider (22–440 lbs) and ±2 lbs / ±10 lbs buttons.
  • Contextual Parameters: Gender chips (Male, Female, Other) and adult age input.

4.2 Precision Body Mass Index (BMI) Engine

Calculates Body Mass Index using the standard algebraic equation: BMI = Weight (kg) / [Height (m)]². The result is strictly rounded to one decimal place (e.g., 170 cm, 70.0 kg → 24.2 kg/m²).

4.3 WHO Adult Classification & Visual Badges

Calculated results are mapped dynamically to WHO adult categories:

  • Underweight — BMI < 18.5 (Risk of nutritional deficiency)
  • Normal Weight — BMI 18.5 to 24.9 (Lowest clinical health risk)
  • Overweight — BMI 25.0 to 29.9 (Elevated cardiovascular risk)
  • Obesity — BMI ≥ 30.0 (High clinical risk)

4.4 Estimated Healthy Weight Range & Target Delta

Computes minimum healthy weight (18.5 × H²) and maximum healthy weight (24.9 × H²) in kilograms. An analysis badge indicates whether the user is within the healthy zone, or how many kilograms they are above/below the normal threshold.

4.5 Segmented Visual Gauge with Animated Cursor

A custom-built horizontal scale displays the four WHO categories across a continuous range (15.0–40.0). An animated needle pointer with a numeric chip smoothly glides to the exact computed BMI position.

4.6 Tailored Dietary & Physical Activity Guidance

Dynamically renders personalized lifestyle guidance covering dietary recommendations (nutritional balance, caloric density, portion awareness) and physical activity guidance (aerobic exercise, resistance training).

4.7 Local Calculation History & Persistent Storage

Calculations are stored locally using browser LocalStorage via SharedPreferences. The history view displays formatted timestamps, BMI values, category badges, and measurements, with options to reload a record, delete individual items, or clear all history.

4.8 One-Tap Viva Examination Demonstration Presets

Provides instant demonstration presets for Underweight (175 cm, 50 kg), Normal (170 cm, 65 kg), Overweight (170 cm, 78 kg), and Obesity (160 cm, 85 kg) for fast external examiner evaluation.

4.9 Theme Support & Health Disclaimer

Supports seamless switching between Material 3 Light and Dark modes. Features the mandatory WHO screening disclaimer regarding clinical scope and professional medical consultation.

static double calculateBmi({ required double weightKg, required double heightCm, }) { if (heightCm <= 0 || weightKg <= 0) { throw ArgumentError('Height and weight must be strictly positive.'); } final double heightMeters = heightCm / 100.0; final double rawBmi = weightKg / (heightMeters * heightMeters); return roundToOneDecimal(rawBmi); } static ({double minWeightKg, double maxWeightKg}) calculateHealthyWeightRange( double heightCm, ) { final double heightM = heightCm / 100.0; final double heightSquared = heightM * heightM; return ( minWeightKg: roundToOneDecimal(18.5 * heightSquared), maxWeightKg: roundToOneDecimal(24.9 * heightSquared), ); }

static double feetAndInchesToCm(int feet, double inches) { return roundToOneDecimal((feet * 30.48) + (inches * 2.54)); } static ({int feet, double inches}) cmToFeetAndInches(double cm) { final double totalInches = cm / 2.54; final int feet = (totalInches / 12).floor(); final double inches = roundToOneDecimal(totalInches % 12); return (feet: feet, inches: inches); } static double lbsToKg(double lbs) => roundToOneDecimal(lbs * 0.45359237); static double kgToLbs(double kg) => roundToOneDecimal(kg / 0.45359237);

6. Deployment Details

VitalScale is deployed as a high-performance Flutter Web application hosted globally on GitHub Pages using an automated GitHub Actions CI/CD pipeline.

6.1 Deployment Process

  1. The Flutter Web project was developed and structured modularly on local environment.
  2. Git was initialized and all code committed to the GitHub repository on the main branch.
  3. A GitHub Actions workflow (.github/workflows/deploy.yml) was created to automate deployment.
  4. The CI/CD runner checks out the repository and sets up the Flutter stable SDK.
  5. The runner executes flutter pub get and runs all unit and widget tests (flutter test).
  6. The production web application is built using: flutter build web --release --base-href "/bmi-calculator-lab/".
  7. The generated build/web artifact is published directly to GitHub Pages.
  8. The live application is accessible securely via HTTPS.

6.2 Deployment Workflow Diagram

Local Flutter Project ↓ Git Commit ↓ GitHub Remote Repository (main branch) ↓ GitHub Actions CI/CD Pipeline ↓ flutter pub get ↓ flutter test (7 Tests Passed, 0 Failed) ↓ flutter build web --release ↓ build/web Artifact Upload ↓ GitHub Pages CDN ↓ Live VitalScale Web Application
